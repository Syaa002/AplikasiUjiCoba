# 📱 Cara Pakai & Live Development di HP - Alat Keuangan Warga (AKW)

Aplikasi PWA ini dibuat khusus agar kamu bisa langsung coding di Visual Studio Code di laptop, dan hasilnya **langsung terlihat detik itu juga di layar HP kamu tanpa perlu refresh** (Hot Reload).

---

## 🚀 Langkah 1: Hubungkan HP & Laptop
Pastikan **HP dan Laptop kamu terhubung ke Wi-Fi / Hotspot yang sama**.

---

## 🌐 Langkah 2: Buka di Browser HP
Buka browser (Google Chrome di Android atau Safari di iPhone), lalu ketik alamat ini:

👉 **`http://192.168.18.41:5173`**

*(Catatan: Jika IP berubah, cek lagi via command `ipconfig` di terminal laptop).*

---

## 📲 Langkah 3: Install / Download ke Layar Utama HP
- **Di Google Chrome (Android):**
  Klik titik 3 di kanan atas -> Pilih **"Instal aplikasi"** atau **"Tambahkan ke Layar Utama"** (atau klik tombol kuning *"📲 Pasang App"* di header aplikasi).
- **Di Safari (iPhone):**
  Klik tombol Share (kotak dengan panah ke atas) -> Pilih **"Add to Home Screen"** (*Tambahkan ke Layar Utama*).

---

## ⚡ Langkah 4: Live Coding di Visual Studio Code
1. Buka folder `D:\AKW-proyek\AKW\AKW-Project` di **Visual Studio Code**.
2. Buka file `index.html` atau `main.js`.
3. Coba ubah teks apa saja.
4. Tekan **`Ctrl + S`** (Save) di Visual Studio Code.
5. **Lihat layar HP kamu:** Teks di HP langsung berganti secara instan tanpa perlu tekan tombol refresh!
