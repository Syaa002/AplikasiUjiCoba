# Alat Keuangan Warga (AKW)

Aplikasi Web & Mobile (PWA / TWA) untuk pengelolaan administrasi dan keuangan warga RT 002 Blok C Perumahan De'Keraton.

## 🚀 Fitur Utama
- **Splash Screen Video**: Animasi awal saat aplikasi dibuka.
- **PWA & TWA Ready**: Dapat diunduh sebagai aplikasi Android (.apk) tanpa bilah URL (Full Screen).
- **Dashboard Keuangan**: Rekap total saldo kas warga, pemasukan, dan pengeluaran per bulan.
- **Data Warga**: Manajemen pencatatan dan pencarian data warga RT.
- **Catat Transaksi**: Input pemasukan (iuran bulanan, PAM lebaran, donasi) dan pengeluaran operasional.
- **Riwayat Kas**: Pencatatan riwayat transaksi lengkap dengan fitur ekspor data.
